一、项目概述
================================================================================

本项目实现了一个基于深度强化学习（DRL）的NOMA（非正交多址）安全传输系统，
用于无线通信中的物理层安全研究。

核心场景：
- 基站通过NOMA同时服务多个合法用户（U1, U2, ...）
- 存在窃听者试图截获信号
- 系统可部署友好干扰器（Jammer）干扰窃听者
- 目标：在满足QoS和功率约束下，最大化保密容量

================================================================================
二、代码结构与功能
================================================================================

1. NOMASecureEnv (环境类)
   - 支持可变用户数量
   - 支持有/无Jammer模式
   - 支持窃听者强度缩放
   - 当前模型：Jammer只干扰窃听者（协作式Jamming）

2. DRL智能体
   - DDPG (Deep Deterministic Policy Gradient)
   - TD3 (Twin Delayed Deep Deterministic Policy Gradient)
   - SAC (Soft Actor-Critic)

3. 基线算法
   - Random: 随机功率分配
   - Equal: 等功率分配
   - Heuristic: 启发式固定比例
   - PSO: 粒子群优化
   - GridSearch: 网格搜索

4. 实验框架
   - Experiment1: 窃听者强度变化实验
   - Experiment2: 用户数量扩展实验

```python
    num_users=2,                # 用户数量
    P_max=15.0,                 # 总功率约束
    noise_power=1.0,            # 噪声功率
    R_min=0.5,                  # 最低速率要求
    eavesdropper_gain_scale=1.0, # 窃听者强度

    L_Je=0.5,                   # Jammer到窃听者路径损耗
    use_jammer=True,            # 是否使用Jammer
    seed=42                     # 随机种子
)
```

八、物理模型说明
================================================================================

8.1 合法用户SINR（可以进行SIC）

弱用户U1:
  gamma_1 = (|h_1|^2 * P_1) / (sum(|h_1|^2 * P_j, j>1) + noise)

强用户Ui:
  gamma_sic = (|h_i|^2 * P_1) / (sum(|h_i|^2 * P_j, j>1) + noise)
  gamma_i = (|h_i|^2 * P_i) / (sum(|h_i|^2 * P_j, j>i) + noise)

8.2 窃听者SINR（不能SIC）

  gamma_e(i) = (|g|^2 * P_i) / (sum(|g|^2 * P_j, j≠i) + |g_J|^2 * P_J + noise)

8.3 保密容量

  C_sec(i) = max(0, log2(1+gamma_i) - log2(1+gamma_e(i)))

8.4 关键假设

  - Jammer只干扰窃听者，不干扰合法用户（协作式Jamming）
  - 合法用户可以进行完美SIC
  - 窃听者不能进行SIC
  - Jammer有独立的功率预算
